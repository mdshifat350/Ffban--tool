# 🚀 GREAT SHIFAT FF ACCOUNT MANAGEMENT TOOL

### PREMIUM EDITION • v2.2 (OB55)

Welcome to **GREAT SHIFAT FF ACCOUNT MANAGEMENT TOOL**, a Python-based command-line project for educational account-management and security workflows.

> **⚠️ DISCLAIMER:** This project is for educational purposes only. Use it only with accounts and data you own or are authorized to manage. It does not automate mass bans, unauthorized account access, or actions intended to disrupt other players. Account reports and enforcement decisions must be handled through Free Fire's official channels.

---

## ✨ Features

- **📂 File Input:** Read authorized test records from `.txt` or `.json` files.
- **🔐 Token Safety:** Learn how to handle your own authentication tokens securely. Never share tokens or passwords.
- **📝 Auto Logging:** Keep local records of tool activity and errors.
- **🎨 Premium UI:** Terminal interface with colors, animations, and ASCII art.

---

## 🛠️ Requirements

- **Termux** (Android) or a Linux-based terminal.
- **Python 3.x**
- Required Python libraries:
  - `requests`
  - `pycryptodome`
  - `protobuf`
  - `urllib3`

---

## 📥 Installation & Usage (Termux)

### Step 1: Update packages and install requirements

Open Termux and run:

```bash
pkg update && pkg upgrade -y
pkg install python git -y
```

### Step 2: Install Python libraries

```bash
pip install requests pycryptodome protobuf urllib3
```

### Step 3: Run the project

```bash
python main.py
```

Replace `main.py` with your actual Python filename if it is different.
